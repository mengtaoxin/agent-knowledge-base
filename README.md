# Agent Knowledge Base

A searchable library of entries from programming with large language models. It stores problems, diagnoses, and short explanations of scripts. It is not an application, and nothing here is meant to be installed or executed.

When a problem shows up in another project, point an agent at this repository and ask it to search here before proposing a new fix.

Documents in this repository are written in English. The file structure is described in [docs/file-structure.md](docs/file-structure.md).
